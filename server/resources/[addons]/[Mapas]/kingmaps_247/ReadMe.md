#### HOW TO INSTALL 
1. Drag and drop the `kingmaps_247` folder to your resource folder 
2. Add `kingmaps_247` to your `server.cfg` (ensure kingmaps_247)
3. Clear server cache and restart the server

#### HOW TO INSTALL IF YOU USE GABZ MLO'S 
1. Drag and drop the `kingmaps_247` folder to your `resource` folder
2. Delete `cfx-gabz-247` in Gabz resource
3. Add `kingmaps_247` to your `server.cfg` (ensure kingmaps_247)
4. Clear server cache and restart the server
