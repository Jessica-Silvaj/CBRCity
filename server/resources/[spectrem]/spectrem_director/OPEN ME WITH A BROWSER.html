Overview

Spectrem Director is an in-game filmmaking and scene-authoring suite for FiveM. It combines actor placement, saved characters, animations, synchronized scenes, cinematic cameras, object editing, replay tools, custom scene composition, and a multi-track Timeline in one consistent interface.

◎
Direct actors

Spawn, dress, animate, arm, position, control, and save reusable peds.

◈
Build scenes

Combine actors, vehicles, effects, cameras, delays, and attachments into repeatable scenes.

▣
Edit time

Arrange clips on dynamic tracks, trim, split, snap, preview, and save complete projects.

◉
Author cameras

Capture keyframes, record live movement, control lenses, focus, shake, guides, and transitions.

◇
Stage objects

Use a native gizmo to place peds, props, and vehicles with multi-selection and precise transforms.

↻
Replay action

Record Ghost, Ped, and Vehicle takes, then reuse them in larger edits.

Extract the production package

Place it in the server's resources directory and name the final folder exactly spectrem_director.

Set the connection string before oxmysql starts. Confirm that oxmysql can connect before enabling Director.

Add the correct start order

Start optional providers first, then Director.

Configure permissions and bridges

Start and verify

Watch the console until database initialization finishes, join with an authorized account, and complete the first-start checklist.

Minimum server.cfg example

set mysql_connection_string "mysql://USER:PASSWORD@127.0.0.1/DATABASE?charset=utf8mb4"
set sv_enableNetEventReassembly true

ensure oxmysql
ensure spectrem_director
i
Keep latent-event reassembly enabledDirector uses FiveM latent transfers for large Ped Replay payloads so they do not overflow the normal reliable-event queue. FiveM enables this feature by default, but declaring set sv_enableNetEventReassembly true explicitly prevents another server preset from disabling it. Restart the complete server after changing this convar.

Client plugins (Script Hook)

If you use client plugins that require Script Hook, the server administrator must add or update this line in the active server.cfg:

sv_scriptHookAllowed 1

Write the command without =. 1 permits Script Hook; 0 disables it. Check that another loaded configuration does not override the value, restart the complete server, and reconnect. Restarting only Director does not reload server.cfg.

This applies to Script Hook-based client plugins. Spectrem Director and normal FiveM appearance or emote resources do not require this setting by themselves.

Access, Scene Admin & public camera

General Director access and individual feature policies are separate. All configuration stays in the commented sections of config.lua.

Configuration example

Config.Access = {
    AdminOnly = true, -- false opens the menu, but feature policies still apply
    AcePermissions = { 'spectrem_director.use' },
}

Config.SceneAdmin = {
    Command = 'sceneadmin',
    CameraCommand = 'camera',
    Licenses = {
        -- 'license:0123456789abcdef0123456789abcdef01234567',
        -- Replace the example with your real player identifier.
    },
    AcePermission = '', -- Optional: 'spectrem_director.manage'
    AdminsHaveToolAccess = true,
    AuditLimit = 60,
    PublicAccess = { camera = true },
    Defaults = { camera = 'enabled', developer = 'admin' },
}

Grant general Director access to a trusted group in server.cfg:

add_ace group.admin spectrem_director.use allow

To authorize policy management through ACE, configure the optional AcePermission shown above and grant it explicitly:

add_ace group.superadmin spectrem_director.manage allow

Policy modes and AdminOnly

Feature modeAdminOnly = trueAdminOnly = false
enabledRequires normal Director access; PublicAccess.camera = true permits public /camera.Available to all players.
adminRequires a SceneAdmin manager and normal Director access.Requires a SceneAdmin manager.
disabledBlocked for everyone, including managers.Blocked for everyone, including managers.

Changing AdminOnly to false opens the main menu to everyone; it does not disable feature policies or authorize everyone to manage them. Keep it true for the public-camera-only setup. The legacy Config.Access.Enabled = true also enables the general access restriction if that field is present.

A SceneAdmin manager is a player listed in Config.SceneAdmin.Licenses or granted the optional Config.SceneAdmin.AcePermission. Having spectrem_director.use alone grants general Director access, not management of policies or use of features in admin mode. AdminsHaveToolAccess = true gives managers general access automatically; if set to false, they also need general access to use restricted tools, but can still manage policies.

Set up and use Scene Admin

  1. Edit the commented Scene Admin / Feature Policies section in the existing config.lua; there is no separate config_admin.lua.
  2. Add full player identifiers, including license: or license2: and their 40-character hexadecimal hash, to Licenses. These are player identifiers, not the server's sv_licenseKey. Documentation examples are placeholders.
  3. Optionally set AcePermission = 'spectrem_director.manage' and grant that exact ACE to the intended group. An empty string disables this alternative; license authorization continues to work.
  4. Keep PublicAccess.camera = true and set the camera policy to enabled for public /camera. Setting it to admin or disabled removes public access. PublicAccess.camera = false makes enabled camera use require normal Director access.
  5. Restart the running resource after editing configuration. For development, use restart spectrem_director_dev; for an installation named spectrem_director, use restart spectrem_director.
  6. Run /sceneadmin, search or filter by category, change individual modes or apply one mode to the filtered results, then select Save changes. Discard changes cancels the current draft; Refresh reloads the current saved policy. Closing a draft with unsaved changes asks before discarding it. Ctrl+S saves and Esc closes the panel.

Command and CameraCommand are stored without a slash and default to sceneadmin and camera. Managers can also open Scene Admin using the shield button in Director. The panel provides English and Spanish text, counts per mode, pending-change indicators, and a history of who changed each feature, when, and its previous/new mode. AuditLimit defaults to 60 and is bounded to 10–100 entries.

Persistence, live changes and recovery

Saved panel choices survive restarts in this resource's KVP storage. They are not written back into config.lua. Existing saved modes take precedence over Defaults, so changing AdminOnly or editing Defaults does not reset saved feature choices. On first use, omitted defaults become admin when general access is restricted, otherwise enabled. Use Restore configuration defaults in the panel to deliberately reapply the current defaults globally.

Saving applies policies to connected players. Revoked tools run their cleanup, and active composed previews/recordings may be stopped; saved projects remain. Existing availability limits supported by config.lua and edit.lua still apply: the panel cannot override a feature disabled there. The UI marks these configuration locks.

Concurrent edits use a revision check. If another manager saves first, your draft is retained but cannot overwrite the newer revision: refresh and reapply the changes. A failed save leaves the active policy unchanged. Invalid saved policy data locks features; an authorized manager can restore defaults from /sceneadmin.

Fixes and verification

The administration integration validates permissions in server handlers as well as client callbacks and commands. Nested camera, Timeline and Custom Scene actions check their required features. Server identity comes from identifiers/ACE, not a role submitted by the UI. The default access list uses the explicit spectrem_director.use ACE instead of the broad command fallback.

The public /camera flow opens Camera Controls directly and returns to gameplay on close, including for managers who entered through the command. F5, /director and /tutorial remain separate entry points. The camera's animation shortcut is hidden for public users. Denied or malformed scene-list responses are normalized to an empty array, fixing the Vue render error Cannot read properties of undefined (reading 'length') seen when access was rejected.

Test with both a manager and a regular player: verify public camera open/close, denied main-menu access with AdminOnly = true, each policy mode, saved settings after restart, and continued restrictions with AdminOnly = false. Automated permission, camera lifecycle, NUI and TypeScript checks passed for this implementation; a live FiveM session is still needed to verify native behavior on your server.

First-start verification

  1. Start the server and confirm oxmysql connects first.
  2. Confirm Director starts without a missing dependency, manifest, or NUI error.
  3. Wait for the database-ready messages before testing saves.
  4. Join with an authorized account and open Director using F5 or /director.
  5. Use a configured manager account to open /sceneadmin, save a feature policy and verify that it survives a resource restart.
  6. With AdminOnly = true, verify a regular player can use public /camera and return to gameplay on close, while F5, /director and /tutorial remain denied. Also verify that disabling the camera removes that access.
  7. Open Cutscene Player using F6 or /cutscenes.
  8. Run /tutorial, verify the spotlight and language selector, then finish the tour. Director should remain open.
  9. Create, save, and reload one ped.
  10. Tune a vehicle, save it under My Vehicles, and spawn it again to verify its mods and liveries.
  11. Create, save, close, and reopen a small Custom Scene.
  12. Create and save a small Timeline project, then preview it.
  13. Preview and cancel a small Object Motion path; confirm the original prop transform is restored.
  14. Draw and preview a two-point Actor Sequence route using the persistent Freecam.
  15. Select a supported door, test both opening directions, then use Back to restore it.
  16. Place one physical Stage Light and verify it in a short Rockstar Editor clip.
  17. Test optional integrations only if they are enabled.

edit.lua & optional integrations

edit.lua is the supported location for server-specific bridges and editable lifecycle hooks. Avoid changing core files when the integration can be expressed here.

Appearance provider

The default provider is native, which uses the built-in ped studio. External appearance systems are optional.

EDIT.ClothingSystem = "native"

If you select an external provider, start it before Director and verify the supplied model, appearance, save, and customization hooks with both freemode and non-freemode models.

External animation-menu bridge

The included bridge targets WC_EMOTES_V8 and is enabled in the shipped editable file. If that menu is not installed, disable the bridge:

EDIT.AnimationBridge.Enabled = false

Supporting a different emote menu means adapting the bridge functions inside edit.lua. If you are not comfortable editing them, ask us on Discord and we will help you set it up.

Weather bridge

Local cinematic overrides use GTA natives. Server-wide weather changes require the configured bridge and permission. Keep framework imports in a separate companion resource; do not add another framework's initialization file to Director's manifest.

Updating safely

  1. Stop the server and back up the Director database tables.
  2. Back up the current production resource.
  3. Save your edited config.lua and edit.lua separately.
  4. Extract the new release into a clean folder.
  5. Compare the new config.lua with your backup and reapply custom values.
  6. Keep the production folder name spectrem_director.
  7. Start the server and allow automatic migrations to complete.
  8. Repeat the first-start verification workflow.

Navigation basics

Open the main interface with F5 or /director. The header provides language selection, saved-scene count, a ? Guided Tutorial button, an Interface settings monitor icon, and entry points to the major tools. The same size button is available in Timeline. Choose 75-200% in 5% steps, or restore the recommended size for your screen (including 1440p and 4K). The maximum adapts to keep controls visible. Changes apply immediately to all panels and save on this device; a personal choice takes precedence over Config.UIScale. The same panel also includes Timeline playback opacity (0-100%) for both full and compact playback views, with a live preview and a reset button. At 0% the playback panel is hidden; at 100% it is fully opaque. The default and reset value are 70%; existing personal choices are preserved. New users can run /tutorial directly; Director opens automatically before the tour begins.

Configure

Guided Tutorial

Run /tutorial from chat, or select the ? button in the Director header to start or restart the tour from step 1. The walkthrough contains 70 steps in nine chapters and uses a moving spotlight to identify the Director control or entry point being explained. Its 12-step Camera chapter covers capture/replacement, motion recording, timing, independent attachment/look targets, optical focus, look/zoom speed, drone banking, framing, output and saving.

New production workflows

Choose Chapters → Advanced Authoring for the replay, traffic, actor and text workflows. These explanations highlight their actual Custom Scene entry buttons; perform the described actions after the tour. The tour never launches a nested recorder, creates traffic or writes a saved scene.

  • Scene placement: G ground snap in move, free-camera and aim modes; heading and actor/prop offsets stay intact. This is separate from Camera's G target lock.
  • Environment and timing: save an environment snapshot, replace it explicitly after live changes, and distinguish clip start from source offset and recorded car delays.
  • Vehicle Replay: driver/passenger seats, weapon-fire playback off by default, names as labels, server-confirmed saves and safe append to folders already referenced by scenes.
  • Traffic Replay: generate stopped cars; use Advanced spawn codes or My Vehicles; replace/remove and ground-place cars; draw rounded routes and delays; record, save and reuse the actual motion.
  • Actor Sequence: walking and weapon styles, waypoint overrides, smooth corners, exact event stops and Preview versus Scrub. Legacy routes retain their old mode until smoothing is enabled.
  • Cinematic Text: bundled fonts, Fixed/Face camera, gizmo placement, occlusion and timing. Use direct EXPORT for text: Rockstar Editor cannot capture its DUI surface.

Scenes & Scenes Fav

Scenes are ready-made synchronized arrangements with actors, animations, and optional objects. Search by name, filter by category, or star a scene for quick access in Scenes Fav.

Combine With props, With weapons and actor-count filters below search. Filters also apply to Favorites. Place with my character appears in the cast dialog only for scenes with exactly one actor: position the scene using your current appearance, then confirm to perform it with the actual player. Cancel returns without starting playback. Start on foot; Stop releases the player and restores temporary scene weapons and ammunition. Scenes with multiple actors keep their normal Place workflow, even if other actors are disabled.

Scene workflow

  1. Select a scene card.
  2. Review its actor and object count.
  3. Enable or disable individual actors and objects.
  4. Choose each actor from presets, a Saved Ped, or a custom model.
  5. Assign a preset or custom weapon where applicable.
  6. Choose loop behavior.
  7. Select Preview to inspect the full scene around its first enabled actor.
  8. Return with Esc, make any cast/object changes, then select Place, position the origin, and confirm.
  9. During placement, press G to snap the whole scene origin to the surface below it. Works in move, free-camera and aim modes; it leaves aim mode to keep the snapped position. Heading and relative actor/prop offsets are preserved, and the scene's own props are ignored by the ground check. If no surface is detected, nothing moves. Fine-tune height with Q/E, then confirm with Enter. Also available when placing scene entries in Custom Scenes or Timeline.
  10. Use the scene controls or parent Custom Scene/Timeline to stop playback.

Adjust Drone banking

Enable Drone mode to reveal the Drone banking slider. Set the maximum tilt from 0° to 45°: 0° smoothly levels the horizon, 15° is the default, and 45° gives stronger banking. This changes tilt when turning, not flight speed or inertia. Fast mouse turns cannot request a tilt beyond the selected limit. The startup default is Config.CinematicCamera.Drone.Banking; live camera recordings store the resulting rotation.

Attach to one entity and look at another

Attachment controls position. Look target controls rotation. With three cars, attach to the middle car using LMB, turn toward the right car using Alt + RMB, then select it with RMB. To track a passing car from a fixed spot, detach and turn off Follow Player, Allow Player Movement and Auto Orbit; select only a look target.

  • Click: RMB locks the aimed entity. Click it again, click empty space, or choose Release to stop tracking.
  • Hold: RMB tracks the selected entity until mouse-up. Keyboard and panel selections remain locked until released.
  • Free: RMB rotates manually. Alt + RMB provides manual rotation in the other modes; N toggles free look and releases tracking.
  • B selects the next look target; V selects the previous one. Neither changes the attachment. Hide the panel with H to use these shortcuts.
  • Target priority: Scene / Timeline first is the default. Scene / Timeline only excludes world entities. All nearby entities permits unrestricted picking. B/V uses stable entity identity order, not changing distance order.
  • Picking a look target releases composition lock but retains the positional mount. Enabling composition lock again releases the independent look target.

Look speed, in the Look target section, sets live turning and tracking speed from 1–100% (default 50%). Lower values give slow pans; higher values aim quickly. It applies to RMB, B/V, panel targets and G. Very low values lag behind fast-moving subjects. Manual rotation smoothing, attachment movement and Drone banking remain unchanged. Authored keyframe playback is unaffected; Live Camera Record stores the resulting turn. Set the startup default with Config.CinematicCamera.LookSpeed.

Zoom speed, under Movement → Lens, controls live zoom from 1–200% (default 100%). Hide the panel with H, then hold Z to zoom in or C to zoom out. Lower values zoom slowly; 100% changes FOV by 25 degrees per second and 200% is twice as fast. This changes FOV, not position. Lens presets still apply directly, authored zoom playback is unchanged, and Live Camera Record captures the resulting FOV. Zoom keys do nothing while the panel is open or a sequence is playing/scrubbing. Startup default: Config.CinematicCamera.ZoomSpeed.

Choose lens focus separately

Follow focus prioritizes the look target, then the attachment or G/sequence target. Focus changes sharpness; it does not steer the camera. Autofocus smooths changes and briefly retains its last valid hit when the ray crosses a gap.

Scene look targets are saved per keyframe independently of the positional anchor and re-resolved if Timeline recreates their entities. A missing scene target waits; a deleted world target is released. Live Camera Record bakes gaze and focus, including B/V switches. World entity handles are not saved as portable references. Text attachment: in Content, refresh the target list, choose a ped, vehicle or object and click Attach / apply anchor. Scene and Timeline subjects are listed first. Cinematic Text is a new guided world-space title system inspired by the strongest authoring ideas from Core Cinematics and Maker Pro, but integrated into Director's existing Custom Scene and Timeline clocks. Open it from Director, add it as a Custom Scene entry, or create/edit its Timeline clip.

The font picker previews 40 offline options: 5 base families and 35 bundled local families. It covers condensed title, elegant serif, modern sans, techno/display, handwritten, and monospaced styles without requiring an Internet connection. Latin and Latin Extended are available across the library, and many families also include Vietnamese glyphs.   1. Content: name the entry, write Unicode or multiline text, and start from Title, Subtitle, Neon, Warning, or a custom style.
  2. Appearance: choose a bundled/system font, color, opacity, alignment, outline, glow, shadow, and world scale.
  3. Movement & timing: enter the exact duration; select None, Fade + slide, Scale, Rise, Typewriter, or Wave and set independent entrance/exit times.

Saved definitions live in the normal Custom Scene or Timeline JSON payload, so no SQL migration is required. Runtime instances are lazy and cleaned up on preview stop, parent playback stop, editor close, or resource shutdown.

Timeline Editor

While editing, keyboard and mouse retain UI focus even with a gamepad connected. Gameplay controls are blocked only in the editor; Freecam, placement and playback release that editing guard.

FREECAM in the top bar, or Move camera beside the inspector, inspects the scene without creating camera keyframes. Use WASD / Q / E to move, move the mouse freely to look, and use Shift / Alt for fast / slow movement. F5 or ESC returns to Timeline and holds the framing, including while editing effects. Use shot camera resumes authored camera scrubbing. Takes without camera clips keep this view; authored cameras take priority during output. Closing Timeline releases Freecam.

  • Effects: click once or press + to insert and inspect an effect at the playhead. Search covers the complete loaded catalog. Move effect and Move camera sit beside its settings; placed, unattached effects expose live X/Y/Z coordinates.
  • Animation placement: choose Ground or Fly above Place in the animation inspector. Ground follows the floor; Fly preserves the placed height. The choice is saved per clip and reused in placement, scrub, Test and output. Existing clips default to Ground.
  • Layer order: new dedicated layers appear at the top. Duplicates appear directly below their original layer. Dropping onto a row inserts below that row. Shared controls reuse their existing track.
  • Expandable groups: Vehicle Replay, Ped Replay, animations, effects and other types have parent rows. Click the arrow to collapse or expand their child tracks. The parent retains an occupancy overview; collapsing never disables playback. The project remembers the view. Use the group button beside TRACKS for a flat view, or workspace settings to collapse/expand all groups. New clips expand their group automatically.
  • Layer ON/OFF: the eye button on each row uses the saved Mute state to exclude that layer from preview and output. It supports undo and is disabled during playback/capture.
  • Reorder type groups: drag a parent header such as Speech or Animation above or below another type. The insertion line marks the destination; the entire group moves with its tracks and subgroups. Clip times stay unchanged. The order is saved and supports undo/redo; a normal click still expands or collapses.
  • Named subgroups: click + beside Animation or another type to create Group 1, Group 2, etc. Rename in the group header. Drag a track label or clip onto the subgroup to assign it without changing its time, even if the group is empty or collapsed. Drop on the type header to ungroup. Compatible library items can be dropped directly into a subgroup; gear > Subgroup is also available. Collapse each independently. Removing a group keeps its tracks. Project saving and undo/redo retain the organization; duplicates inherit their source group. The old Collections block has been removed from the clip inspector.
  • Select in view: activate the button and click an active Timeline actor, vehicle or owned prop. Unattached effects can be selected within 24 screen pixels of their emitter origin; select attached effects from their track. Map objects and inactive clips are excluded.

TEST, Play from, ACTION! and EXPORT hide the local player's ped during Timeline takes, including the recording countdown. Stop, cancellation, failed preparation and resource shutdown restore the previous visibility.

Timeline is a multi-track nonlinear editor. Projects can be created, saved, searched, loaded, renamed, duplicated, and deleted. Unsaved work remains a local draft until saved to the database.

Add and organize clips

  • Drag an option onto Timeline or double-click it to add at the playhead.
  • Tracks are created only when needed.
  • Scene, Animation, Stage Light, Cinematic Text, Effect, Vehicle Replay, and Ped Replay clips receive independent tracks for clearer organization.
  • Camera, Speech, and World & Time content share type-specific tracks.
  • Drag track headers or use their arrows to reorder them.
  • Mute tracks to exclude playback and lock them to prevent edits.

Edit clips

Move, trim from either edge, split, copy, paste, duplicate, delete, or select multiple clips. Use Ctrl for individual multi-selection and Shift for a range. Right-click opens context actions.

Audio reference tracks (FiveManage and YouTube)

MP3, OGG and WAV files are supported when playable by the browser. Dashboard pages are not audio files. You can also paste a YouTube video link, including a shared youtu.be link. These settings combine: 50% listening volume with a 50% clip gives 25% output. Zero silences reference audio without changing game sounds. Both settings are saved with the project.

Use a direct audio file for precise editing. The player is released on Stop, closing Timeline or completion.

Replay systems

Ghost Replay

Records the controlled subject's movement for repeatable blocking. Press E to stop, name the take, save it, and add it to a larger production. Use shorter test takes while calibrating routes.

Ped Replay

Adaptive playback: the recorded route guides native movement while weapon changes, shots, rolls, cover, jumps and reloads can finish. Small differences are accepted and the route is recalculated after actions. Unavailable cover falls back to locomotion; only large, sustained drift outside protected actions triggers recovery. Live takes can vary with the environment, while scrubbing still inspects the recorded pose. Record a new take for combat-roll phases and confirmed shots; older takes cannot supply missing action data. Settings are in Config.PedReplay; PlaybackMode = "legacy" restores the previous controller.

Records only the active player, including appearance, movement, actions, combat state, and vehicles used by that player. Nearby NPCs are not scanned or captured. Press E to finish, then name and save. Before placement, configure the actor model and appearance; prop attachments and drift correction are supported.

Vehicle Replay / Vehicle Sessions

Keep recording in a used folder: saving another take is allowed even when a saved Custom Scene or Timeline references that folder. Save uploads only the new take; the server appends it to its committed data without replacing or reordering previous takes. You do not need to empty the scene or restart the game. Deleting or fully replacing referenced recordings remains protected.

If another save changed the folder during upload, the new take remains pending while the folder refreshes. Press Save again after the refresh message. Failed uploads do not replace saved takes. Do not close the game/resource while a take is unsaved. Deploy matching client, server and compiled UI files together; old servers are rejected before append data is uploaded. No SQL migration or server.cfg change is needed.

Large folder uploads: a disconnect naming spectrem:server:updateVehicleSessionChunk concerns network transfer, not a fixed 14-vehicle limit. Updates use 8 KiB latent chunks, with at most four in flight and a combined 256 KiB/s budget. The server acknowledges consecutive blocks before the database commit; progress keeps long uploads alive. Incomplete or stalled uploads are cancelled without committing partial recordings. The existing 32 MiB encoded-folder limit depends on recording duration and detail, not only vehicle count. No server.cfg changes or SQL reinstall are required. Update matching client and server resource files and restart when nobody is recording; older servers are rejected before bulk upload.

After stopping with E, name the take, click Save, and wait for confirmation before recording the next take in the same folder. Names are display labels; previous takes load by session ID. A new folder has no ghosts until its first take is saved. The next capture waits for all previous ghost vehicles to spawn. If startup fails, saved takes remain intact; the menu reports the failure and F8 logs beginning with [Spectrem][VehiclePreview] identify the loading or model error. No SQL migration is required.

Enter a vehicle first. Open or create a session, record one or more takes after the countdown, and press E to stop. Finalization briefly freezes the vehicle, removes invalid trailing samples, and restores the player and vehicle to the origin.

After recording, save, discard, record another take, test, delete, or select one or multiple takes for Custom Scenes or Timeline. Full paint, mods, extras, lights and liveries are captured with the take. Per-vehicle settings include driver appearance, siren, collision, motion, drift correction, engine, invincibility, visible damage, freeze behavior, and prop or ped attachments.

Select a Vehicle Replay clip in Timeline, or open its settings in Custom Scenes, to replace each recorded model with a preset from My Vehicles. The replacement is stored with the production, so editing the library later does not alter the scene.

Replay recorded weapon fire is off by default. Enable it in Vehicle Replay settings only when the take needs gunfire or a water cannon. Real weapon events are still captured; disabling playback does not erase them. Existing saved scenes and timeline clips keep their explicit setting: switch it off there too if it was saved enabled. Unarmed cars no longer treat the shared attack/gesture control as mounted-weapon fire or receive native firing tasks from replay. The global default is Config.GhostReplay.ReplayVehicleWeapons = false.

Driver-operated mounted-weapon fire is captured as compact timed events. When enabled, native playback supports GTA weaponized vehicles. Ballistic mode replays a captured weapon hash when the native firing command does not respond; resource-defined turrets, muzzle animations, or weapons that never expose a native hash require a custom bridge.

Traffic Replay: traffic for races and pursuits

  1. Open/create a Vehicle Replay folder and choose Traffic Replay.
  2. Add here places a zone at your player position. Use View scene / move and Open controls to move around and add more zones. The crosshair button moves a center to you; the trash button removes that zone.
  3. Set radius (30–180 m), vehicle count, target speed (10–120 km/h) and behavior. Normal respects lights; Flow ignores lights while still using road routing and avoidance.
  4. Generate / refresh places local cars and drivers stopped, with the handbrake on and no driving task. Placement checks road direction, lane count, median gap and obstacles. Check the actual count: occupied/unavailable points can reduce it. Regenerate after editing zone settings.
  5. Use Vehicles in the scene to review the fleet. Click a car's name to mark it in the world, then use View scene / move to inspect it. Select a model from the pool, a customized car from My Vehicles, or an installed car model name, then Apply. Only that car is replaced; an invalid, oversized or blocked replacement keeps the original. The trash button removes only that generated car. Editing is locked while a replacement loads. Generate / refresh resets the fleet and these choices.
  6. Optional: select Advanced · manual placement. Add cars by spawn code or from My Vehicles, without generating a zone. Typing k lists installed car codes starting with k; click a suggestion or press Enter for the first result. Full addon codes are also accepted. Suggestions use the cached catalog, with no request per keystroke. Saved cars retain their customization; presets are not modified.
  7. Add vehicle places a stopped car 8 m in front of you; keep that spot clear. Position on ground opens a translucent vehicle preview using scene-placement controls, without gizmo axes. WASD moves the car, the mouse wheel rotates it, Shift/Ctrl select fast/precise movement, and Space switches to/from free camera (WASD + Q/E, mouse look). X toggles placement at the camera's aim point. Wheel contact keeps the car grounded and aligned to slopes; Q/E cannot lift the car in move mode. Enter confirms a clear, grounded position; an invalid position keeps the preview open. Backspace cancels and restores that car. Opacity, collision and camera/player controls are restored on exit; other cars remain stopped. Adjust speed and behavior independently per car.
  8. The placement camera starts behind the car, like scene placement. Movement follows the view: D/A move car and camera right/left together, regardless of the car's heading. Wheel rotation stays in place. If the ground rejects a step, neither the car nor its following camera advances.
  9. Align to traffic explicitly snaps one car to a clear nearby lane and its native heading. Failed alignment preserves its previous position. Automatic placement preserves the game's node direction, including one-way roads with reversed edge ordering, and rejects unrelated crossing/parallel-road geometry. Ground placement keeps the wheels supported but does not choose a lane or direction automatically: off-road or wrong-way cars may turn to join the road. Switching modes keeps the fleet; Generate / refresh replaces it. Generated and manual cars share the same total limit.
  10. On any staged car, expand Vehicle trajectory and choose Draw route. The first point is anchored to the car. Use WASD + mouse for Freecam, Q/E up/down and Shift/Ctrl fast/precise. Left click adds road-surface points ahead of the vehicle. Backspace undoes a point (not the start), Enter saves, and Esc cancels without changing the previous route.
  11. The blue line previews rounded corners. Corner smoothing (2–20 m; default 8) rounds more of each corner, limited by neighboring segments. Keep the line and car body inside the road. Speed reduces ahead of bends; the car stops at the endpoint. Start delay (0–30 s, shorter than the recording) coordinates individual departures on the shared clock. Match delays for parallel cars or stagger them for spaced arrivals.
  12. Edit route reopens the points; Use automatic traffic removes the route. Replacing a car keeps its route. Confirming ground placement or successfully aligning the car clears it; cancellation or failure preserves it. Regenerating/closing clears the fleet and routes. Save the recorded take to retain the actual motion. Limits: 2–64 points including start, at least 3 m apart, within 600 m of the start and up to 1,500 m total. Avoid walls, steep height changes, reverse starts and extremely sharp turns.
  13. Choose a duration and Record traffic. The initial stopped frame is captured before cars are released according to their delays. Cars without an authored route keep automatic road AI. Press E to stop early. Only this tool's generated/manually added vehicles are captured, on a shared clock. Record your race or chase separately.
  14. Live traffic is removed on completion. Name and Save the take, then Configure & Place it in Custom Scenes or Timeline. NPC drivers are supplied by default and can be changed per seat.

Defaults: 4 zones, 16 vehicles total, 120 seconds, 24,000 samples total. Sampling adapts to the budget. Centers must be within 450 m of the player. Unattended staged fleets expire after 180 seconds. Cancel clears only this tool's vehicles; no world traffic or saved recordings are deleted. Zone presets are remembered on the local browser/client; saved takes retain the cars' captured appearance using the existing Vehicle Session database and acknowledged upload path.

Zones are spawn areas, not barriers. Cars without authored routes follow GTA's road network and may leave the radius. They are not repeatedly assigned random destinations across medians. Shortcuts, oncoming-lane avoidance and off-road avoidance are disabled. Authored routes use physical driving with moving look-ahead targets and anticipatory braking, not per-frame position/rotation writes. Neither mode guarantees collision-free driving: GTA AI can deviate or get stuck on narrow roads, custom maps or in congestion. Sustained route deviation over 12 m ends capture and retains the available take for review. Missing entities also stop capture early. Traffic never respawns or teleports during recording. Route drawing pauses preview expiry. Roadless areas and interiors may not support automatic placement. Traffic is local, not a synchronized multiplayer population; playback follows captured frames, including start delays, instead of making new AI decisions. Configure models, driver, availability, limits and estimated lane spacing (LaneWidth, default 3.25 m) in Config.TrafficReplay. No server.cfg changes, SQL migration or extra resource are required. Finish this capture before another Vehicle/Ped/Chase recording.

Chase Replay

The menu does not open
  • Test /director in case another resource uses F5.

  • Check that Director and oxmysql started successfully.
  • Inspect the client F8 console for the first NUI error.

  • Restart after editing config.lua. Use Scene Admin's restore action to deliberately reapply current defaults.
Scene Admin does not open or a change did not apply
  • Add the full player license: or license2: identifier in Config.SceneAdmin.Licenses, or configure and grant the optional management ACE.
  • Finish placement, recording or an active camera before opening the panel.
  • Save the draft. On a revision conflict, refresh and reapply it.
  • Check for a configuration lock or a saved mode overriding Defaults.
  • If saved policy data is invalid, an authorized manager can restore configuration defaults from the panel.
Vue reports undefined length after an access denial

The corrected UI normalizes denied scene-list responses to an empty array. Use the matching client scripts and current compiled web/build, then restart the resource. Public players should open /camera, which does not load the Director scene browser.

Database saves fail or content does not load
  • Confirm the connection string and selected database.
  • Grant CREATE/ALTER/SELECT/INSERT/UPDATE/DELETE permissions.
  • Read the first oxmysql error before later Director messages.
  • Do not restart during an active save.
  • Remove project/scene references before deleting a used source.
The NUI is blank or reports Failed to fetch
  • Re-extract the resource — a partial or interrupted extraction is the most common cause.
  • Clear the FiveM client cache and reconnect.
  • Inspect F8 for the first callback name and error.
  • Wait for lazy-loaded clips before starting preview.
Ped Replay disconnects with a reliable network event size overflow
  • Add set sv_enableNetEventReassembly true to server.cfg and restart the complete server.
  • Reconnect the FiveM client so it receives the current client scripts.
  • If the reported event is still spectrem:server:savePedReplayChunk, an older Director copy is still running. The current transport uses savePedReplayLatent.
  • Do not raise general event-rate limits; use Director's bounded latent transport.
A Script Hook client plugin does not load

Review Client plugins (Script Hook), including sv_scriptHookAllowed 1 in the active server.cfg, then restart the complete server and reconnect. Confirm the plugin supports your FiveM version.

The animation bridge is Offline
  • Start the configured external animation resource before Director.
  • Enable the bridge in edit.lua.
  • Verify event and export names match the provider version.
  • Select the external animation before selecting its ped.
Object Spooner cursor or controls feel locked
  • Release RMB to return the UI cursor.
  • Click outside search or numeric fields before using shortcuts.
  • Check FiveM key mappings for conflicting bindings.
Actor Sequencer previews but the actor does not move
  • Confirm the route has a starting point and at least one destination.
  • Walk/Run belongs to the segment leading to the next point; Start is only the spawn marker.
  • Make sure the selected actor source still resolves and is not owned by another preview.
  • Stop with Backspace, reopen Review and inspect the first Actor Sequencer message in F8.
Door Director cannot select a map or MLO door
  • Release RMB before clicking so the world-selection cursor owns the mouse.
  • Entity-backed addon doors are detected automatically.
  • A Door System door without a CObject needs its archetype in Config.DoorDirector.RegisteredDoorModels.
  • Baked geometry exposed as neither an object nor a Door System entry cannot be animated by script.
Stage Lighting Freecam or fixture cannot start
  • Confirm the Stage Lighting YTYP and all 15 physical fixture assets are present in stream/[Stage Lighting].
  • Press Esc/Backspace once to close another authoring camera or full-screen interface, then reopen the light.
  • Finish an active gizmo session before Preview or Save.
  • After a GTA/FiveM artifact update, test a short day and night Rockstar Editor clip.
Cinematic Text is absent from a recording
  • First confirm that the text appears in live Preview and that its Timeline track is not muted.
  • Use direct EXPORT with Spectrem Export when the final MP4 must include the text.
  • Rockstar Editor cannot capture FiveM DUI surfaces; ACTION! is intentionally rejected when Cinematic Text is present.
  • If live Preview is also blank, close another active authoring tool, reopen Cinematic Text, and inspect the first DUI or Freecam error in F8.
Object Motion camera appears extremely close
  • Use the Manual FOV control or Z/C and verify the selected lens.
  • Select the affected keyframe and save/replace it after correcting FOV.
  • Object Motion has its own work-camera state; camera effects are not baked into the prop path.
A camera keyframe adjustment is not saved

Select the exact keyframe diamond, adjust the pose, then click Save frame or Replace. Moving the camera alone does not overwrite a recorded keyframe.

Timeline preview does not start
  • Confirm there is at least one valid, unmuted clip.
  • Wait until referenced clips finish loading.
  • Unlock tracks before editing.
  • Press Backspace once to cancel preparation or active playback, then retry.
  • Check F8 and the server console for the first reported callback or storage failure.
Performance drops or the server reports hitches
  • Make sure you are on the latest release.
  • Reduce crowd size, environment radius, density, effect count, and active replay length.
  • Avoid several administrators saving large takes simultaneously.
  • Monitor database latency and slow queries.
  • Keep default bounded transfer and storage settings unless profiling proves a change is safe.
